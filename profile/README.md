# BUAA-MCVR-Lab
BUAA MCVR 实验室共享信息

## 1. 这是什么？

- `https://github.com/BUAA-MCVR-Lab` 是一个 github Organization, 本项目主要用于 BUAA Junjun Pan 教授所指导的 MCVR 实验室内部的信息共享。
- 当前页面是一个公开可见的外部页面，用于提供一些 **外部可见** 的材料（比如实验室官网，可公开的实验室相关信息等）。
- 当前页面目前的管理员为 `premierbob@qq.com (GGN_2015)`，如有任何疑问欢迎邮件联系。

## 2. 实验室官方网站

- [https://vr-pan-junjun.github.io/](https://vr-pan-junjun.github.io/)
- 其中可以查询实验室论文，实验室人员以及去向等等，如需更新请联系官方网站管理员 `premierbob@qq.com (GGN_2015)`。

## 3. 其他共享材料

- 原则上，本项目中应该收录实验室成员发布的开源软件与算法。
  - 如果实验室的朋友们有想要公开的自己 public 项目，欢迎联系管理员为我们的共享与整理事业添砖加瓦。
- 对于实验室内部的共享材料，我们也会以 private 项目的形式收录。
  - 例如一些尚未发表但有共享意义的项目、一些实验室专有的数据集等等。
